## 🛠️ Emulator Setup

### Step 1 — Install .NET Runtime

Download and install **.NET 8.0 Desktop Runtime** from Microsoft's official website.

```bash
dotnet --list-runtimes
```

### Step 2 — Extract Emulator

Right-click the downloaded archive → **Extract All…** → choose `C:\Emulators\`.

### Step 3 — Launch Emulator

Double-click the emulator executable. Allow firewall access on first launch.

### Step 4 — Install Firmware

**Tools → Install Firmware → Install from ZIP**. Select your firmware file.

### Step 5 — Add Keys

Place `prod.keys` and `title.keys` in:

```
%APPDATA%\Ryujinx\system\
```

| ❌ Black screen | GPU driver | Update drivers |

| ❌ Low FPS | CPU bottleneck | Enable multi-core |
| ❌ Audio issues | Wrong backend | Switch to OpenAL |

| ❌ Shader stutter | Cache building | Let it compile |
